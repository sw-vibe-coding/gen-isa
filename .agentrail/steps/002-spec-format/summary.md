Locked format choices: one spec per ISA, snake_case keys, top-level [[fixed_pair]] for register pairs, class-tagged registers for reserved/pc/sp/fp, repeated mnemonics with distinct enum names allowed, opcode.formats array for multi-form support, encoding_style switch (bit_fields | rom_table) so COR24 can keep hand-supplied encoder.
